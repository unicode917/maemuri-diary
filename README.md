# 🍰 마무리 다이어리

하루를 조각으로 나누고, 떠오르는 아이디어는 인박스로, **하루 1개는 반드시 끝내는** 개인 다이어리 앱(PWA).
아이디어는 많고 마무리가 약한 발산형을 위해 만들었다.

**👉 앱 열기: https://unicode917.github.io/maemuri-diary/**

## 설치

- **아이폰**: Safari로 위 주소 열기 → 공유 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 열기 → ⋮ → **앱 설치**
- **PC (Chrome/Edge)**: 주소창 오른쪽 **설치** 아이콘

## 하루 사용법 — 3번만 열면 된다

| 언제 | 할 것 |
|------|-------|
| ☀️ 아침 2분 | 팝업에서 체크리스트 + **🎯 오늘의 마무리 1개** 고르기 |
| 🕐 낮 | **⏱️ 지금 조각**만 보기. 딴생각은 오른쪽 아래 **💡** |
| 🌙 저녁 3분 | 🌙 정리 → 한 줄 일기 → worklog 📋 복사 |
| 📅 주 1회 | 💡 인박스 정리 + ⚙️ **폰 ↔ PC 동기화** |

## 마무리 장치

- 🎯 오늘의 1개 + 🔥 연속 일수 · 끝내면 축하 🎉
- 🔒 진행 프로젝트 최대 3개 · 🏁 완료 조건 없으면 시작 불가
- 💡 아이디어 48시간 숙성 후에만 프로젝트로 승격
- 🧊 7일 손 안 댄 프로젝트 알림 · ✂️ 분량 나누기에 마무리 버퍼
- 📈 실제 속도로 완료 예상일 재계산
- 🤖 Claude에게 계획 맡기기 (프롬프트 복사 ↔ JSON 붙여넣기, API 키 불필요)

## 폰 ↔ PC 함께 쓰기

서버가 없어서 기록은 **각 기기 안에만** 있다. ⚙️ 설정에서:

1. 보내는 기기: **📤 보내기** (폰: 공유 시트로 카톡 나와의 채팅·드라이브 / PC: 파일 저장)
2. 받는 기기: **📥 받아서 합치기**

양쪽에서 각각 추가·수정한 기록이 모두 살아남는다(같은 기록은 최근 수정 우선, 삭제도 전파).
반대 방향도 한 번 하면 두 기기가 같아진다.

## 데이터 · 보안

- 기록은 그 기기 브라우저(localStorage)에만 저장. 외부 서버·분석·광고 스크립트 없음, CSP로 외부 전송 차단
- 비밀번호·API Key·토큰·주민/카드/계좌번호처럼 보이는 내용은 **저장 자체가 차단**
- 동기화 파일엔 개인 기록이 들어 있으니 내 계정 공간에만 둘 것
